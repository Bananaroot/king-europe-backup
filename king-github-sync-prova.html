👑 KING · GitHub Sync PROVA

Prototipo completamente separato dal magazzino. Nessun timer e nessuna richiesta automatica: GitHub viene contattato soltanto quando premi Salva operazione o Leggi archivio.

1 · Archivio privato di prova

Protezione: non usare il repository pubblico del BACKUP, non salvare il token nel codice e non condividerlo. Il token resta nella memoria della pagina, non viene scritto in localStorage, JSON o GitHub. Questa prova usa un token sul dispositivo: non è ancora una soluzione definitiva per i collaboratori.

2 · Simula una modifica al magazzino

Ogni clic su Salva crea un evento con ID unico. Se la rete cade, resta una copia locale in attesa sul dispositivo: riaprendo questa pagina puoi riprovare.

3 · Esito

Nessuna operazione eseguita.

L'archivio appare qui dopo la lettura.
