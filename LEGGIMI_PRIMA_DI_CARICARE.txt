INSTALLAZIONE SU GITHUB (IMPORTANTE):
1. Salva una copia del repository attuale.
2. ESTRAI LO ZIP sul telefono o computer. Github Pages NON apre automaticamente un archivio ZIP caricato nel repository.
3. Apri la cartella estratta king-europe-backup-main e carica IL SUO CONTENUTO nella directory principale del repository king-europe-backup, NON la cartella esterna e NON il file zip.
4. Sostituisci i file omonimi; lascia invariati i file extra esistenti su GitHub.
5. Verifica https://bananaroot.github.io/king-europe-backup/test-benessere.html e /database-scientifico.html
