# Changelog V2
- Tassonomia multifaccetta estensibile: vitamine, minerali, composti, organi/sistemi, outcome, fonti, rischi, popolazioni, uso storico.
- Schema atomico delle affermazioni con provenance e riferimenti di pagina.
- Rubriche da 1 a 10 **solo con dati sufficienti**; NULL per dati mancanti; nessun punteggio di sicurezza complessivo.
- Distinzione livello sostanza / livello prodotto con dose e controllo qualità.
- Base JSON V1 conservata, estesa in modo non distruttivo.
