← Torna al gestionale

1. Proteggi i dati già presenti

Scarica una copia dello stato attuale prima di qualsiasi ripristino. Se non hai ancora inserito nulla, puoi comunque procedere.

2. Seleziona il JSON originale

Seleziona il file king-europeJson .json che hai esportato dal gestionale originale. Il file viene letto solo su questo dispositivo: non viene caricato su GitHub né su Supabase.

⚠️ La copia GitHub è pubblica, ma il tuo JSON non verrà pubblicato. I dati importati rimarranno nel browser di questo dispositivo. Se cancelli i dati del browser, potresti perderli.

3. Ripristina prodotti e magazzino

Conserva gli stessi dati delle schede: SKU, nomi, prezzi, collegamenti, quantità, scatole e fotografie incorporate. Non modifica ordini, account e altri dati del gestionale locale.

Come funziona

Questa pagina usa l'archivio localStorage del gestionale di emergenza nello stesso dominio GitHub Pages. Dopo il ripristino, apri il magazzino e controlla le foto. Le modifiche successive resteranno locali; non vengono automaticamente salvate nel repository GitHub.

Se appare «memoria insufficiente», nessuna importazione viene considerata riuscita: conserva il JSON originale e non cancellarlo.
